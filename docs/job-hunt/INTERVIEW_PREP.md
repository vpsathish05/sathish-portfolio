# 🎤 Interview Preparation Guide

## Technical Interview Topics

### 1. LLM Fundamentals
- [ ] Transformer architecture basics
- [ ] Attention mechanism
- [ ] Tokenization strategies
- [ ] Context windows and limitations
- [ ] Fine-tuning vs prompting vs RAG

### 2. RAG System Design
- [ ] Chunking strategies (fixed, semantic, recursive)
- [ ] Embedding models comparison
- [ ] Vector database selection
- [ ] Hybrid search (BM25 + vector)
- [ ] Reranking strategies
- [ ] Evaluation metrics (recall@k, MRR)

### 3. Production AI Systems
- [ ] Latency optimization
- [ ] Cost management (token budgets)
- [ ] Caching strategies
- [ ] Error handling and fallbacks
- [ ] Monitoring and observability
- [ ] A/B testing for AI features

### 4. System Design (AI-specific)
- [ ] "Design a RAG system for legal documents"
- [ ] "Build an AI chatbot handling 1M queries/day"
- [ ] "Design a document extraction pipeline"
- [ ] "Architect a multi-agent system"

### 5. Coding (Python focus)
- [ ] LeetCode medium problems
- [ ] String manipulation
- [ ] Data structures (especially for retrieval)
- [ ] API design
- [ ] Async programming

## Questions to Ask Interviewers

### About the Role
- What does a typical day/week look like?
- What's the biggest challenge the team is facing?
- How do you measure success in this role?

### About the Team
- How large is the AI/ML team?
- What's the split between research and production?
- How do AI engineers collaborate with product?

### About Technology
- What's your current AI/ML stack?
- How do you handle model evaluation?
- What's your approach to production AI systems?

### About Growth
- What does career progression look like?
- How do you support learning and development?
- Are there opportunities to publish or speak?
