## 📁 Project Deep Dives

### Contract Intelligence Platform (Flagship)

**The Problem:**
Enterprise client had 200-page contracts requiring manual extraction. Each batch took 260+ hours of human labor. Error-prone, expensive, couldn't scale.

**My Solution:**
Built an end-to-end AI pipeline:
1. Document ingestion → S3 storage
2. PaddleOCR PP-OCRv5 for text extraction
3. Custom table detection for complex layouts
4. Qwen SLM for entity extraction
5. Confidence scoring + validation rules
6. Human-in-the-loop for edge cases
7. Salesforce + MongoDB integration

**Technical Challenges Solved:**
- Scanned documents with varying quality → adaptive preprocessing
- Tables spanning multiple pages → context preservation
- Handwritten annotations → OCR confidence filtering
- Complex nested tables → custom parsing logic

**Results:**
- 260 hours → 26 minutes (99% reduction)
- 85-90% straight-through processing
- <1% error rate
- Published on Medium

**What I Learned:**
- Production AI is about the system, not the model
- Confidence thresholds are harder than they sound
- Human-in-the-loop is essential, not optional

### AI Research Chatbot

**The Problem:**
Healthcare researchers spent hours manually reading papers from PubMed, Google Scholar, Semantic Scholar. They needed synthesized insights, not just search results.

**My Solution:**
RAG-based chatbot with:
1. Multi-source retrieval (PubMed, Scholar APIs)
2. Semantic chunking + embedding
3. Hybrid search (BM25 + vector)
4. Intelligent caching layer
5. Citation tracking
6. Next.js frontend

**Technical Challenges:**
- Multiple data sources with different schemas
- Academic papers are long → smart chunking
- Same queries repeated → caching strategy
- Need citations → source tracking

**Results:**
- 1K+ daily queries
- 10x faster for cached queries
- Reduced research time from hours to minutes

### Enterprise Data Platform

**The Problem:**
Private equity client needed unified view across 20+ data sources. Manual reporting took days. No version history.

**My Solution:**
Medallion architecture data platform:
1. Bronze: Raw data ingestion (Azure Data Factory)
2. Silver: Cleaned, validated data (dbt transformations)
3. Gold: Business-ready aggregations (Redshift)
4. SCD Type 2 for complete history
5. Power BI dashboards

**Results:**
- 5M+ daily records processed
- 3 critical reports automated (ARR, Pricing, Price List)
- Query time reduced 50%
- Full audit trail with SCD Type 2
