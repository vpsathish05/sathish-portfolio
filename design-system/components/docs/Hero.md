# Hero
The opening stage: mono eyebrow, the name in `display-xl` with an italic saffron accent, one statement, two actions, and the live AgentGraph.

- Consumer provides `eyebrow` (role · focus — never an employer or client name), `name` (first line), `accent` (second line, rendered italic in `signal-ink` — the signature move), `statement` (≤ 30 words; wrap the key phrase in `<b>` to lift it to `ink`), and `actions` (one primary + one secondary `Button`).
- `graph` configures the AgentGraph: `nodes` (five labels: top, right, bottom-right, bottom-left, left), `hot` (indexes drawn in `current` with data packets flowing in), `core` (centre label). Pass `false` for a text-only hero.
- Sits on `surface-sunk` with the dot-grid texture and `radius-lg`. One per site.
- Don't add a photo here; the graph *is* the portrait.
