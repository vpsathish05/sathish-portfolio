# Testimonial
One endorsement, large, with a role-based attribution.

- Consumer provides `quote` (≤ 35 words), `name`, `role`, optional `source` ("Shared with permission", "LinkedIn recommendation").
- Attribute by **role and industry** ("Head of Data · Financial services") unless the person has agreed to be named. Never name a client company without written permission.
- One per section; two or three in a row at most.
