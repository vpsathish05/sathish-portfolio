# Metric
One true fact as a big serif number over a mono label.

- Consumer provides `value`, optional `unit` (italic `signal-ink` suffix: "rd", "%", "ms"), `label` (UPPERCASE mono, ≤ 4 words) and optional `note`.
- Wrap 3–4 in `.sg-metrics` for the auto-fit row.
- Only measured or verifiable numbers. If you don't have one, use a non-confidential fact — never a vanity stat, never a client figure.
- The preview values are samples; replace them.
