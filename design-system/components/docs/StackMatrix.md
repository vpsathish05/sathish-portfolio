# StackMatrix
Your tech stack grouped by layer, with honest depth markers instead of skill bars.

- Consumer provides `groups` — `{label, items: [{name, level}]}` with `level` = `daily` (ice diamond), `proficient` (mint diamond) or `familiar` (outline). The legend and screen-reader text name each level; colour is never alone.
- 4–6 groups, ≤ 6 items each. Only list what you'd defend in an interview.
