# ResumeSection
A labelled band of the résumé (Core skills, Experience, Certifications, Education, Publications).

- Consumer provides `title` and `children`. Order for the UK and US: Personal statement (in ResumeHeader) → Core skills → Experience → Certifications → Education → Publications/Awards.
- Prints cleanly: set `data-theme="paper"` on the page and use A4 (UK, 2 pages) or US Letter (1–2 pages).
