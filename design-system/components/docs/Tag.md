# Tag
A mono chip for stack items, project kinds and status.

- **neutral** (default) for stacks: name the real tool — "PostgreSQL", not "Database".
- **current** + `live` for availability ("Shipping agents") and success states ("complete").
- **signal** for one featured or live marker per view.
- `dot` adds a square marker; `live` makes it breathe (stops under reduced motion). Status always carries its word — never a dot alone.
- Keep to 1–3 words; a row of tags caps at about six.
