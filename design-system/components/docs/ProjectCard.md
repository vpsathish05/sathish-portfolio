# ProjectCard
A case-study teaser; the whole card is one link.

- Consumer provides `index` ("/01"), `kind` ("MCP · Analytics"), `title`, `summary` (1–2 sentences: what it does for whom), optional `outcome` (the result in one line), `tags` (real stack), `href`, and for the lead project `featured` + `visual` (an architecture sketch or screenshot on the dot-grid well).
- Hover lifts 3px, adds `shadow-card` and draws a 2px `signal` rule across the top — never a coloured left border.
- Layout: one featured card beside two stacked cards (`.sg-grid-2`). Show three, not ten.
- Titles are descriptive and generic ("Support Triage Agent"), never an internal codename; kinds name the industry, never the client.
