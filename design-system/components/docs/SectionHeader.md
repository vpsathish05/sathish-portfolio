# SectionHeader
Opens every section: a numbered mono index, a serif title with optional italic accent, a lede, and an optional aside action.

- Consumer provides `index` ("01"), `label` ("Selected work"), `title`, optional `accent` (the italic `signal-ink` phrase — use it on the last 1–3 words), `lede` (≤ 2 sentences), `aside` (a ghost `Button`).
- Indices must match NavBar order. Leave `space-9` above each header.
