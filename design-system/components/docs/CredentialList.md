# CredentialList
Certifications, education, awards and memberships as one scannable list.

- Consumer provides `items` — `{kind: 'cert'|'degree'|'award'|'membership', title, issuer, year, href?}`; `href` adds a "Verify ↗" link to the credential page.
- Newest first; certifications before education for senior roles. Never include ID numbers.
