# ContactBand
The saffron closing stage: the single biggest colour moment on the site.

- Consumer provides `eyebrow` ("05 — Contact"), `title` + `accent` (italic end-phrase), `lede` (who should get in touch and why), `email`, and `links` (≤ 4 outbound profiles).
- Everything on it is `on-signal`; the focus ring switches to `on-signal` automatically.
- Use once, at the end of the home page. Because it *is* the page's signal, keep other saffron off-screen when it is in view.
